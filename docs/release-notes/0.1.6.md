Fix catalog backups and exports to SMB network shares.

- Catalog backups to SMB shares and NAS folders no longer fail with “Operation not supported (os error 45)” when the share does not support a full disk-cache flush.
- The same fix applies to photo exports, portable edit sidecars and catalog snapshots before an upgrade.

Thanks to etrigan63 for the detailed diagnosis in issue #1.
