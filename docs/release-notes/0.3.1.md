Recipe grain defaults and more reliable add-on downloads.

- Built-in Fujifilm recipes now apply their published Grain Effect and size alongside Clarity and Sharpness. All 84 Fuji X Weekly recipes and the three Community Recipes were checked against their published settings. Grain remains editable with Emulsion's sliders.
- Existing photo edits keep their saved grain, clarity and sharpening. Select a recipe again to apply its updated defaults.
- Add-on downloads try a verified Emulsion mirror when Microsoft's ONNX Runtime download is unavailable. Both sources must match the same pinned checksum. Failed downloads now show curl's detailed error.

Known: the Fuji recipe editor currently supports colour recipes. Recipe detail settings use Emulsion's own grain, clarity and sharpening; they are not an exact reproduction of the camera's processing. A recipe's camera dynamic-range setting, noise reduction and exposure compensation are not applied. Some colours, particularly saturated greens, can still differ from the camera's JPEG. Very heavy exports of GFX100RF photos can still run out of memory.

Please report any problems at github.com/mowerol/emulsion/issues, with the log file attached (Help › Show Log in Finder).
