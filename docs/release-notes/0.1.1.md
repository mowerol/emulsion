Fixes for the first beta's two biggest problems.

- LUT looks now apply. In 0.1.0 every look from the bundled film packs failed to load, and the photo stopped updating while one was chosen, so sliders seemed frozen.
- Sliders are much smoother, especially with a large library. Each slider movement used to rewrite the whole library catalog; now only the edited photo is updated, once the slider settles.

Please keep reporting problems at github.com/mowerol/emulsion/issues, with the log file attached (Help › Show Log in Finder).
