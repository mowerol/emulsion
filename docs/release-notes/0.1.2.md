Sliders keep up in a large library.

- Dragging a slider is about twice as smooth with a big folder open. With 22,000 photos open, each slider movement used to re-read the whole folder and library several times; that work is now skipped unless the edit changes what is shown.
- Saving an edit to the library catalog no longer interrupts a drag: it waits until you let go, and only the edited photo's folders are written.
- New installs start with the six Emulsion looks in Favourites.

Known: about a second after opening a photo, the full-resolution image arrives in the background, and a slider held at that moment can pause briefly.

Please keep reporting problems at github.com/mowerol/emulsion/issues, with the log file attached (Help › Show Log in Finder).
