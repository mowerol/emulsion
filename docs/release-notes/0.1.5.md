Catalog saving, custom workspaces and stronger film effects.

- Edits, virtual copies and edit history now save in Emulsion’s catalog. Existing edits migrate automatically, with a catalog backup before upgrading. Existing sidecars are left untouched; photos on disconnected drives migrate when available.
- Settings → Catalog offers separate options to keep writing portable edit sidecars and to share ratings and metadata through XMP. Both are off by default; existing XMP metadata is still read.
- Failed saves remain visible with a retry action. Emulsion stays open when changes cannot be saved, and recovered edits and versions are available through Earlier edits.
- Create and name custom workspaces, arrange editing groups across tabs, and switch between them from the Workspace menu.
- Remove photos from the Library or move their files to the Trash from the photo menu or Photo menu.
- Halation has a stronger range for new adjustments. Saved Halation keeps its previous rendering; set it to zero and raise it again to try the new range.
- Glow and Glow size are now available on individual masks.

Important: keep catalog backups enabled. Older Emulsion builds cannot open the upgraded catalog. Keep existing JSON sidecars until their migration is verified and you have a fresh catalog backup.

Known: a slider held while the full-resolution image arrives in the background can still pause briefly.

Please keep reporting problems at github.com/mowerol/emulsion/issues, with the log file attached (Help › Show Log in Finder).
