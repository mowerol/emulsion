Faster Heal updates and more reliable Heal and Clone previews.

- Heal updates sooner after you release its source, with the same healing result.
- Heal and Clone keep refreshing while a replacement patch is being calculated. If the retouch worker fails, the tools recover instead of staying on the old patch.
- Brush is now the default shape for Heal and Clone. Your chosen shape is remembered when switching tools; Remove continues to start with Brush.

Known: a slider held while the full-resolution image arrives in the background can still pause briefly.

Please keep reporting problems at github.com/mowerol/emulsion/issues, with the log file attached (Help › Show Log in Finder).
