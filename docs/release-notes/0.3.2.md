More control over light and finishing touches for your exports.

- Shadows, Highlights, Blacks and Whites now adapt to each photo, with stronger recovery for backlit subjects and consistent −100 to +100 ranges. Existing edits keep their saved tone processing; clear or reset a control to use the new processing. (#51)
- Add text or image watermarks to exported photos, with a preview and controls for placement, size and opacity. Save watermark settings with your export presets. (#50)
- Large Remove spots use more of the surrounding photo to improve reconstruction context. Existing Remove patches regenerate once when needed. (#48, #49)

Known: Remove can still produce smudges or invented details, especially on difficult backgrounds. The Fuji recipe editor currently supports colour recipes. Recipe detail settings use Emulsion's own grain, clarity and sharpening; a recipe's camera dynamic-range setting, noise reduction and exposure compensation are not applied. Some colours, particularly saturated greens, can still differ from the camera's JPEG. Very heavy exports of GFX100RF photos can still run out of memory.

Please report any problems at github.com/mowerol/emulsion/issues, with the log file attached (Help › Show Log in Finder).
