Faster first zoom, with a steadier photo while zooming.

- The first zoom into a RAW photo reaches full detail sooner. Full-resolution decoding uses more CPU cores, with the same decoded pixels and image quality.
- The photo keeps its shape while zooming changes the canvas size, and each new frame appears together with its matching dimensions.

Known: a slider held while the full-resolution image arrives in the background can still pause briefly.

Please keep reporting problems at github.com/mowerol/emulsion/issues, with the log file attached (Help › Show Log in Finder).
