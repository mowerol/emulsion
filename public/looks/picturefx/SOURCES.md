# PictureFX legacy collection

19 unmodified 13-point Cube LUTs by Marc Roovers (PictureFX / digicrea.be),
distributed by G’MIC: https://gmic.eu/color_presets/picturefx/picturefx_cube.zip
Archive SHA-256: 4dd2ed51376622c0a605d9e9fb865afb06cff64e56d871f49c6d2e0cf820cec2

CC BY-SA 4.0. Author-written license/credits retained as README.PictureFX.txt,
preserved at https://github.com/cedeber/hald-clut/blob/41cb940e6a85a5f4c18ff42f177db0f6be027a8b/HaldCLUT/PictureFX/README.txt
The original digicrea.be site is offline. Only the 19 looks accompanying that
legacy README are included; six additional Faux Infrared files are excluded.

G’MIC converted/resampled the original Hald LUTs to Cube; Emulsion makes no further
changes to Cube values. Cube adaptations remain CC BY-SA 4.0; hashes are recorded
in src/film/lut-catalogue.json. Assets retain their own license, separately from
the app. These are legacy effects, not current CineStill/SX-70 releases.

Input assumption: display sRGB, consistent with the conventional G’MIC image
workflow. The legacy README does not explicitly specify primaries/transfer.
