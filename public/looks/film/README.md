# Film stocks

Baked by `tools/spektrabake` from darktable's spektrafilm engine (darktable `c247126f9a7a2c3cdfc0f675a7698c24710438ca`) and the darktable-spektrafilm data pack 0.3.3 (`b15cfe18fb35ec15084f78c986b0ebc730338e6e`), with darktable's default parameters, each film on its target print paper. Film modeling powered by spektrafilm, © Andrea Volpato.

These files are derived from the spektrafilm data and are licensed like it, under CC BY-SA 4.0 with the spektrafilm preamble (see LICENSE, copied unchanged from the pack). Changes: the film and print were run through darktable's engine and sampled on two 65³ lattices (scene light to film log exposure; film density to the print), stored in half floats with the density curves and coupler data, in Emulsion's `.film` format (`src/engine/film.ts`).
